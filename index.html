Como funciona o agendamento?

Quando você marca um conteúdo como estudado, a primeira revisão é agendada automaticamente para o dia seguinte. Ao concluir uma revisão, você informa a qualidade da lembrança: Difícil (revisar amanhã), Bom (aumenta o intervalo) ou Fácil (aumenta mais o intervalo). É um agendamento simplificado, ajustável, e não equivale ao algoritmo do Anki.

Planejamento de aulas e estudos

Cadastre cada conteúdo com a matéria e a data da aula. Mantenha a situação “Aula pendente de estudo” até começar a estudá-lo. A partir da conclusão, você poderá acompanhar as revisões programadas.

Backup e importação

Os dados são mantidos somente neste navegador usando armazenamento local. Se você limpar os dados do navegador, mudar de dispositivo ou usar navegação privada, pode perdê-los. Exporte um arquivo JSON para guardar seus registros.
